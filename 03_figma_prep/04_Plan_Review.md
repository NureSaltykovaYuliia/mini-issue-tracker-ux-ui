## 0. Межі перевірки

## 2. Реєстр знайдених дефектів та зауважень (Defect Register)

1. **DEF-01 (HIGH):** Відсутній окремий тест унікальності ID при послідовному створенні двох заявок. -> *Виправлено (додано CR-08).*
2. **DEF-02 (HIGH):** Тести коментарів не перевіряють збереження даних після повторного відкриття екрана. -> *Виправлено (додано перевірку в CM).*
3. **DEF-03 (HIGH):** Елемент `Change assignee` розширює функціонал до повторного призначення (reassign/unassign). -> *Виправлено (обмежено призначенням).*
4. **DEF-04 (HIGH):** Відсутній окремий тест для ролі `Team Member (non-assignee)` при спробі змінити статус. -> *Виправлено (додано PERM-08).*
5. **DEF-05..07 (MEDIUM):** Тести списку `Important` вимагають розділення комбінованих перевірок на окремі тест-кейси. -> *Виправлено.*
6. **DEF-08 (HIGH):** Екран `S-01` не повинен містити згенерованих форм логіна/пароля. -> *Виправлено (залишено boundary annotation).*
7. **DEF-09 (MEDIUM):** Окремі поля помилок та дати не мають закріпленого формату. -> *Виправлено (позначено як neutral copy/D-03).*

## 3. Перевірка спеціальних бізнес-правил та ризиків

* **Чи може Team Lead (non-assignee) змінювати статус?** Ні, заборонено (AC-07.4).
* **Чи містить модальне вікно створення зайві поля?** Ні, тільки `Title` та `Description` (US-01).
* **Чи відображається High + Resolved у вкладці Important Issues?** Так, відображається (BR-09.1).
* **Чи є вихід зі статусу Closed?** Ні, статус `Closed` остаточний (BR-08.1).
* **Чи включено відкладені функції (US-09 attachments, AI)?** Ні, їх строго виключено з MVP.

## 4. Підсумковий висновок та рекомендації

* **Первинний висновок аудитора:** `NOT READY` (для фінальної здачі без правок), але **READY для внесення локальних правок**.
* **Виконані коригувальні дії:**
  1. Додано тест унікальності ID (`CR-08`).
  2. Додано крок перезавантаження сторінки в тестах коментарів (`CM-01..03`).
  3. Обмежено поле призначення первинним вибором 1 виконавця без reassign.
  4. Додано окремий тест для `Member non-assignee` (`PERM-08`).
  5. Зафіксовано всі знайдені дефекти DEF-01..DEF-09 у файлі `Defect_Change_Log.md` та внесено відповідні виправлення в `03_Screen_Contracts.md`.
